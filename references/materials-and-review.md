# 材料准备与递交前复核

## 按事实挑证据

| 要说明什么 | 可核对的材料和动作 |
| --- | --- |
| 身份和适用类别 | 对照在用护照的个人资料页、签发及到期信息，核对表单姓名和护照详情。身份证件、姓名变更证明、旧护照和补充页按个人情况与当前清单准备。公开示例用代号。 |
| 访问目的和停留 | 写清访问目的、在澳主要安排、预计抵离日期。计划可以标成拟定。探亲访友可用邀请信说明关系、目的、住宿和对方是否出资，并核对相应证明。 |
| 旅行资金 | 从预计交通、住宿和日常开支以及各人分摊出发。境外 Tourist 官方页面把覆盖三个月的逐项银行流水列为资金证据示例。工资单、税务记录、定存等视情况选用。别人出资时核对关系、承诺承担的项目和可用资金。 |
| 离澳安排 | 在职者可用准假和返岗信息，学生可用在读和开学安排，自雇或自由职业者可用真实经营、合同、收款或返程后工作安排，退休者可按情况说明养老金和国内生活安排。只采用能支撑本人真实情况的材料。 |
| 个案要求 | 未成年人优先核对监护关系、未同行家长同意和住宿安排，读官网对应章节的 Form 1229、法定声明和 Form 1257 条件。Form 54、照片、户籍和其他文件查当前清单、细类页面及补件要求。 |

没有工资单、房产或出境记录时，用实际情况说明，寻找能支持同一事实的材料。先把「未确认」「无此经历」「无法提供某份文件」分别写清。工作状态、旅行史、签证史和旧护照分别问，短答「无」按所指字段记录。

## 递交前逐项对照

- **日期** 核对出发地离境、抵澳、离澳、回到居住国和准假范围。用各地点当地日期，夜航跨日单列。逐晚核对住宿，包括夜航无住宿和跨城切换。先确认差异是时区还是实质冲突。
- **同行** 共享事实对齐，个人目的各自填写。同行可以共享酒店，但要按本人确认的住宿安排、活动及付款证据填写。对照「表单、行程、说明信、邀请或资助文件」。能否跨 stream 使用同一团组，按官方团组指南与当次页面核对。
- **资金** 按机票、住宿、日常开支逐项写实际付款人。公司可能报销、已明确承诺、已经报销分别记录。款项来源含糊时用中性表述并请本人核实。受限资产单列，房车购置价不当现值，同一笔款不重复累加。
- **版本** 变更日期、同行人、出资人或护照后，指出哪些表格、说明和附件索引要同步。原件照原样保存。译文应能逐项对应原件的姓名、日期、币种金额及页码，机器草稿交给实际译者核实，译者信息和签名据实填写。
- **上传** 每份材料映射到当前申请人的实际栏目和下拉选项。若 Travel history 显示 Required 但只列盖章页，分别核对「无相关经历」和「有旅行但无章」的真实情况。有旅行但无章时，可准备旅行日期、目的地、无章原因和已有的相关佐证。查当前页面是否接受缺件说明或替代证据；未看到适用入口时保留草稿，通过官方渠道确认怎样递交。保持真实的旅行史答案。
- **文件** 用清楚的彩色扫描，保持页序、方向、可读性和签名完整。多页同一文件合并时保留完整范围；同一申请内同份材料通常只附一次。对加密或有数字签名的文件先查官方指引和出具方方案，原件单独保存。Home Affairs 通用指引写明多数申请每人最多 60 份，照片有单独限制，其他文件通常每份最多 5 MB。遇到错误按当次页面及官方上传说明排查。英文文件名是整理方法。

## 自己递交与跟进

整理附件时，可以先列「原文件｜建议英文名｜上传类别｜状态」四列。英文名用内容加可选数字序号，例如 `01_Passport.pdf`、`02_Travel_Itinerary.pdf`、`03_Bank_Statements.pdf`。有原件和译文时可用 `National_ID_Original.pdf` 和 `National_ID_English.pdf` 区分。沿用实际扩展名，避免在文件名写证件号码。附件类别以本人页面所列为准，上传后核对已收到。需要实际改名时，核对不会重名，把原件和上传副本分别保管。

通过官方入口进入 ImmiAccount → 按实际情况填写并核对材料 → 本人核对声明、支付和递交 → 保存回执并看 Messages。处理顺序和标签以页面为准。上传、提交和获批分别核对。

已扣款但不确定是否提交时，由本人核对 My applications summary 中该申请的状态及 Messages 中的官方确认。Submitted 表示已成功递交，Received 表示已收到、将进入评估。支付凭证用于对照交易。若状态和扣款记录不一致，先查官方帮助或联系内政部，确认后再决定是否重试，以免重复付款或申请。

收到补件、体检或生物识别通知时，按通知的内容和期限办。发现错误时读官方纠错指引。获批后核对签证条件和有效期，再安排正式预订。相关入口见 [官方依据](official-sources.md)。
