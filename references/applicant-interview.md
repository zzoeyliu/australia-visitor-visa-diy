# 申请人访谈与材料准备建议

用于澳大利亚境外 Visitor visa (subclass 600) Tourist stream 的材料准备。先弄清旅行事实，再找可验证的证据，给出下一步。向用户说明，访谈是为了缩小准备范围，可用代号、区间或月份，不方便答的可跳过；官方表格仍须由本人按题目如实填写。

## 第一轮：确认人在何处、为什么去

根据已知信息选问，通常两到四组。已有答案直接复用；仅缺少一两个字段时，直接问该字段。

- **基本信息**：开始个性化访谈时，如果称呼、年龄未提供，用一句话问「怎么称呼你（昵称或代号即可）？大概年龄或年龄段？」多人申请时确认是否有未满 18 岁的申请人；如果年龄已能判断，就不重复问。首次访谈无需法定姓名或完整生日；正式提交前，由本人按表格提示核对护照姓名和证件信息。
- **地点和身份**：持哪个国家或地区签发的什么护照？通常在哪个城市和国家或地区生活，现在人在哪？预计递交及等决定时是否都在澳洲境外？长期在护照签发国之外生活的，若与返程有关，再问其当地居留身份类别及返程时是否仍能入境；不用号码或地址。
- **行程和人**：这次主要去做什么、什么时候去、待多久、离澳后去哪里？有没有探访对象或同行人（用代号、说关系即可）？多人分别问活动。实际涉及工作、提供服务、商务或就医，或会在澳洲境内递交时，先核对对应路径，再决定是否继续境外旅游细类访谈。
- **进度**：刚计划、正在准备，还是已递交或收到补件？已递交者围绕官方通知和当前事项来问，不要求从头交代。

## 第二轮：资金、离澳安排与个案情况

只追问影响当前材料建议的内容；可把三组问题合在一条消息。申请人若跳过某项，标「未提供」，不要推断为没有或不利。

1. **工作或学习、收入和费用**：现在是在职、自由职业、经营、就学、退休，还是待业等？在中国或常住地有什么收入来源（工资、项目、经营、租金、养老金等），近期大约是多少、什么币种、按月还是不定期？可答区间或只说来源。估算行程费用，谁实际付机票、住宿和日常开销，各有多少可动用资金？有资助时问关系、具体承担项、钱如何可用以及已有的证明类型。分别记录收入、余额和可获得的资助，避免重复计算。仅提供住宿不等于承担全部旅费。
2. **婚姻、家庭和离澳后安排**：如果愿意，可说已婚、未婚、有伴侣或不方便回答；如果家庭安排与行程或离澳理由有关，再问人在哪里、是否同行、有无具体照护等责任，无需家人姓名。离澳后会回到哪儿？有什么已经安排的返岗、开课、项目交付、经营、照护或其他义务，什么时候需要到场，有什么现成证据？如果返回第三国，核对可返回当地的身份，不默认人人都回中国。婚姻只在能说明实际行程、费用或责任时进入材料建议。
3. **过往记录与额外要求**：是否有过签证被拒、取消、逾期或违反条件？可先答有、无、不确定或跳过。若有，先看当次表格要求，再问用户愿意给出的去识别摘要，区分过去决定和这次事实；无需贴整份通知。旅游经历按实际说明，首次出境不是未达门槛。遇到未满 18 岁，按官网核对家长同意等事项；健康、品行或其他专项要求按当前细类和通知核对，常规访谈不收病历或其他敏感记录。

聊天中不索取或回显证件号、完整出生日期、家庭地址、雇主或亲属的个人联系方式、银行账号、整份流水或未脱敏文件。需要判断证据时，先问有哪种文件，必要时只请用户摘出相关的去识别字段；查询官网只用通用问题。

## 哪些申请更容易说明，哪些要先补证

依据见 [官方依据](official-sources.md)。法规要求有真实短期访问意图、能负担停留期间的开销，并符合相应细类及其他条件。以下是根据官方证据指引给出的准备建议，不是内政部的打分表。

| 访谈中发现的情况 | 先做什么 |
| --- | --- |
| 访问目的、拟定日期、费用承担和离澳后的计划讲得清楚，手上的材料相互印证 | 这类申请的关键事实比较容易说明。用简短行程、费用分摊和能证明离澳后安排的少量相关文件核对表单；不因准备较齐就预判获批。 |
| 行程长、开销与现有资金对不上、近期有较大入账，或资助只说「有人帮忙」 | 先列这趟旅行的实际预算，确认可用金额和谁付哪项。说明真实款项来源；有资助就准备相应的资助说明及能力证据。如果预算确有缺口，就按实际可负担的行程重新规划或等资金落实。 |
| 只写「会回国」，没有具体计划；工作、学习或收入情况与所申报行程对不上 | 找实际安排及证据：在职可看准假和返岗，在读可看在读及课程安排，自由职业或经营可看真实项目、收款和返程后安排，退休或暂未工作可梳理实际收入、可用资金及已存在的家庭或其他安排。按本人情况选择，不要求买房、补造工作或新编义务。 |
| 过去有拒签、取消或不合规，或者真实目的与拟选细类可能冲突 | 先读去识别的官方理由或核对正确细类，再看哪些事实发生了变化以及有什么证据。按表格如实答；涉及复审、取消、复杂身份或法律判断，给合资格澳洲法律执业者或注册移民代理的官方查找途径。 |

单身、没有房产、收入不固定或第一次出境，本身不能据此判断获签难度。公开报告的国籍和历史期间汇总也不能回答「单身自由职业者谁更容易获签」。如果用户问成功率，简短说明统计口径，回到能核实的事实和证据缺口。

输出时先用一两句概括已知事实，区分自述、已见材料和未知信息；再给一至三项最值得先做的动作，每项写明「要说明什么｜可用材料｜还缺什么」。路径未定时先解决路径。材料准备建议不等于资格认定；不要编造事实、设置自定最低收入或存款线、要求用户为显示余额而临时凑款，或建议隐去真实目的和过往记录。
