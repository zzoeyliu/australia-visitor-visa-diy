# 澳洲 600 旅游签材料自查 Skill

适合计划在澳大利亚境外自行申请 Visitor visa (subclass 600) Tourist stream 的中文用户。用 AI 整理申请材料、核对行程和费用分摊，并检查表单、行程单和说明信是否一致。

## 怎么用

1. 在本仓库的 Releases 下载 ZIP，解压后将完整的 Skill 文件夹导入支持 Skill 的 AI 工具。保留 `SKILL.md`、`assets` 和 `references` 的目录结构。
2. 可以先用[虚构案例](assets/demo.md)试一遍。准备自己的材料时，可以问「我想在澳洲境外自行申请 600 旅游签。先问我几个问题，再按我的情况列出要优先准备和核对的材料。」
3. 在聊天里用昵称或代号，上传资料前遮住证件号、银行账号和申请编号。递交前按官方签证页面和自己的 ImmiAccount 清单复核。
